# 'Farmlike' public issue tracker

This repository probably feels pretty empty.
That's because it doesn't contain the game's source code. it's just here as a public place to track progress, collect feedback, and share updates on my game, Farmlike (working title).

Feel free to:
- Report bugs or quirks you run into during any playtest session.
- Suggest features or improvements
- Have open discussions about the direction of the game

Sorry for the nosy developers, but the actual source code lives in a private repository and isn't shared here. 

If you'd like to help me build my game, simply open an issue to report a bug, suggest a feature, or ask a question. 

Thanks for following along with development!
